## Execution evidence

- The initial expanded matrix passed Arabic and English at 390 and 1366 pixels using synthetic owner and agent sessions. The final administrator continuation passed four combinations, adding the merge conflict, bulk tag, sequence enrollment/stop, populated notification actions, lost/reopen/won and report period tests. Administrator actions include reports, scoring, automation, assignment policy, sequences and notifications.
- The API suites passed 90 and 69 checks. The production Next.js build passed. Tests use loopback, embedded PostgreSQL, synthetic channels and delayed sequence scheduling with external delivery disabled.

## Measured workflow changes and manual acceptance

- Saving a new customer opens the profile in the same action. The prior flow needed a directory lookup and another profile action after saving.
- The report currency row opens the same currency scope in one action. Previously the destination mixed currencies and required a separate filter.
- Saving a CRM rule now exposes **Open saved rule**. One click opens that exact rule. The previous workflow opened Automations, switched to the saved editor or found the rule in the list, and selected it.

For a first-use session, prepare a disposable workspace, two staff accounts, a customer with an inbox conversation, a deal linked to a removable stage, an XLSX file with two sheets, and a notification addressed to one staff member. Give the employee the outcomes “create a customer, add a follow-up from their profile, then complete it from Today” and “add and remove an existing customer from a list”. Give the manager “replace the stage without losing its deal”, “reconcile one report amount with the records behind it”, and “preview, save, enable, then disable a synthetic automation”. Record first click, time, actions, completion, help requested and any role confusion without coaching. On actual Android repeat profile forms with the keyboard open in portrait, landscape and Chrome Desktop Site. No independent employee, independent manager, or physical Android device was available in this run. Keep release acceptance open.
