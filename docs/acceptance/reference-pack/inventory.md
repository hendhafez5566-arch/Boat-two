The interactive reference separates catalog, editor, WhatsApp preview, local orders, CRM and templates. The extended reference adds catalog selection, configuration, draft generation, readiness, customer preview and experimental release. Reference persistence and publishing are local simulations. Live sending, payments, production deployment and destructive operations are outside this pass.
