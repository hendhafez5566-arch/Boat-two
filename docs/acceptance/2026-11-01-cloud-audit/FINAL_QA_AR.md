## الإصلاحات

الإصلاحات الستة الأصلية أُعيد قبول أربعة منها سحابيًا: إغلاق الأدوات، إخفاء تشخيص المحاكي، الترويسة، وتعليمات النهاية. الاستيراد وExcel ناجحان محليًا، لكن القبول السحابي لهما لم يكتمل؛ لا تُعتبر محاولة رفع الملف دليل نجاح أو عطل منتج.

**G07 / P3:** جدول CRM يتحدث بينما عدّاد الترويسة يبقى قديمًا. تكرر بعد إنشاء عميل يدويًا وبعد عميل وارد من الويدجت. السبب تحميل workspace مرة واحدة. الإصلاح يعيد تحميل الاستخدام بعد تغييرات العملاء وتقدم الاستيراد وتغير المسار، ويتجاهل نتائج الطلبات القديمة. تحقق سحابي بعد النشر للإنشاء باللغتين ثم inbound والتنقل. لا تغيير على API أو schema أو Meta.

أُصلحت تجهيزات المراجعة أيضًا: انتظار الخوادم بالتسلسل، توجيه widget-config ومصدر snippet، وتشغيل tick الحقيقي لصندوق الأحداث الداخلي في وضع الاختبار. الإرسال الخارجي معطل. هذه إصلاحات لبيئة الاختبار، وليست أعطالًا منسوبة لإنتاج المالك.

ملاحظة UX/P3 باقية: نموذج الحقل الإداري ظاهر للموظف، لكن الخادم يرفض حفظه؛ لم يظهر تجاوز صلاحية. قائمة الحساب في الموبايل فتحت عبر Enter (صورة22)، أما نقر الأداة داخل iframe فتعثر؛ لا يُدعى اختبار اللمس.
