# دفعة مطابقة Message Templates

تاريخ الفحص: 8 نوفمبر 2026. استكمال PR #14 من `9812afbe`؛ لا مشروع أو محرر أو محرك جديد.

## المرجع المشاهد

فُتح BotSailor Message Templates ثم Create → Mixed Template دون حفظ أو تقديم أو مزامنة. النموذج يظهر داخل محتوى المدير ومعه Back to templates. الترتيب: Basic Information، Template Category، Header Type، Message Content، Footer Text، Buttons، ومعاينة جانبية. القياسات الحقيقية موجودة في `template-reference-metrics.json`؛ viewport المرصود 1363×936 فقط. لم تُرفع لقطة الحساب كاملة للمستودع العام لأنها تتضمن بيانات تعريف الحساب.

## التنفيذ

- استبدال نافذة إنشاء/تحرير المسودة داخل Bot Manager بنموذج داخل الصفحة، مع الرجوع إلى القائمة وإبقاء البحث والصفحة والفرز.
- نفس TemplateDraftForm ونفس عقد الحفظ؛ mode=manager يطبق ترتيب وعمودي المرجع. الاستعمال الافتراضي في بقية الصفحات يحتفظ بترتيبه وضوابطه، مع تعطيل التحرير أثناء طلب الحفظ.
- CSS module خاص بالنموذج: حدود وبطاقات وحقول وخطوط مأخوذة من Computed Styles، توزيع 7/12 و5/12 مع gutter24، وفواصل14. تنسيق العربية يعتمد اتجاه الصفحة وخصائص منطقية؛ عرض عمود واحد عند ضيق الشاشة. لم يُختبر عرض المتصفح الجديد بعد.
- Utility/Marketing وخمسة أنواع ترويسة مرتبطة بالحالة والحفظ الفعلي؛ Authentication/OTP يبقى فجوة صريحة لأن عقد الخادم يرفضه. لا أزرار نجاح أو أنواع قوالب زائفة.
- اختيار 71 رمز لغة شوهد في المرجع ويتوافق مع عقد API، مع أسماء عربية واحتفاظ برمز قديم عند إعادة الفتح. قيمة default في المرجع غير مدعومة في عقد Boat ولا تعرض كلغة قابلة للحفظ.
- Save Draft يبقى حفظ مسودة حقيقيًا. Save/Submit يحفظ أولًا ثم يفتح تأكيد التقديم الموجود؛ استدعاء Meta لا يحدث قبل التأكيد. نجاح الحفظ لا يسمى اعتمادًا من المزود. طلب submit نفسه يبقى خلف بوابة التشغيل الحقيقية.
- لم يتغير Backend أو قاعدة البيانات لهذه الدفعة. أداة QA الجديدة تزرع قناة WhatsApp اصطناعية في الخادم المحلي المعزول فقط، خلف BOAT_TEMPLATE_QA، ولا تتصل بمزود.

## نتائج القبول

| الفحص | النتيجة | الدليل والحدود |
|---|---|---|
| قياسات BotSailor وترتيب إنشاء Mixed | PASS للفحص المرجعي | DOM وComputed Styles حيان؛ لا حفظ/تقديم |
| إنشاء/استرجاع وتعديل مسودة مدعومة | PASS للخادم | template-studio-http.json؛ Nest/PGlite فعلي وبيانات اصطناعية |
| منع فقد تحديث بمراجعة قديمة | PASS للخادم | HTTP409 واختبار بقاء التعديل الصحيح |
| المتغيرات/عينات الوسائط/OTP غير المدعوم | PASS للتحقق | HTTP400 دون إنشاء سجلات خاطئة |
| Owner/Admin/Agent وعزل الشركات | PASS للخادم | HTTP حقيقي؛ Agent403 وشركة أخرى404 |
| منع نجاح تقديم مزود وهمي | PASS للبوابة | submit503 ويبقى DRAFT؛ لا قبول مزود حقيقي |
| حفظ البيانات في نموذجي manager/default | PASS لفحص العرض على الخادم | 20 حالة populated render، وجميع71 لغة تتحقق بالعقد الفعلي؛ ليس اختبار نقر |
| TypeScript/ESLint/بناء Web | راجع سجل البناء المرفق | لا يثبت المطابقة البصرية |
| نقر النموذج المعدل وحفظه في المتصفح | BLOCKED | النسخة المعدلة غير منشورة؛ الجلسة السحابية الحالية تعرض النسخة السابقة |
| قبل/بعد وRTL/LTR والمقاسات الخمسة | BLOCKED | لا صور Boat معدلة أو مقارنة بكسلية أُنجزت في هذه الدفعة |
| التقديم الفعلي إلى Meta | BLOCKED | ممنوع اختبار مزود/قناة حقيقيين؛ لم تُستخدم مفاتيح حقيقية |

كل7 اختبارات HTTP نجحت. أول محاولة تجهيز fixture استخدمت اسم tenantId بدل claim tid في JWT، فرفضت الزرع؛ أُصلح fixture ثم نجح التشغيل دون تغيير شروط القبول أو المنتج.
