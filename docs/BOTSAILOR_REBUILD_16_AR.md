# مطابقة إدارة العميل والأتمتة في صندوق الوارد

قورنت شاشة BotSailor مباشرة يوم 28 أكتوبر 2026، بما فيها فتح اختيار Assign Custom Fields وقراءة تعريفات الحقول الموجودة دون اختيار قيمة أو حفظ.

## التنفيذ
- إضافة اختيار الحقل من كتالوج CRM داخل Automation & Flow، وتحرير القيمة من نافذة تدعم النص والرقم والتاريخ ونعم/لا.
- الحفظ الجزئي عبر PATCH profile وexpectedUpdatedAt، دون استبدال السمات الأخرى. القيمة الفارغة تمثل null، مع الحفاظ على 0 وfalse.
- عرض الحقول المسجلة بأسمائها المقروءة وزر تحرير لكل قيمة؛ عدم عرض السمات التقنية غير المسجلة كأنها حقول مخصصة، والقيم null لا تظهر كتعيينات.
- إضافة مكون مستقل لتسلسلات العميل: اختيار تسلسل نشط من نفس القناة، زر إلحاق صريح يوضح بدء الرسائل المجدولة، وإيقاف إلحاق العميل مع إظهار الحالة والموعد التالي. owner/admin فقط وفق API الحالي.
- منع اختيار تسلسل نشط ملحق بالفعل، وتقييد الإرسال بطلب جارٍ واحد. لا تفعيل لحسابات أو قنوات جديدة.
- دعم إزالة العميل من قائمة من داخل لوحة الوارد عبر API العضوية الموجود؛ لا حذف للقائمة نفسها.
- نقل القسم والتوزيع التلقائي تحت «المزيد» وتخفيف وزن عناوين الحقول لتقريب ترتيب الأتمتة من المرجع.

## التحقق
- 12 اختبارًا ناجحًا: اختبارات تحويل الأنواع، PostgreSQL لحفظ 0 وfalse والتاريخ وتفريغ الحقل والحفاظ على باقي البيانات، عزل الشركات، رفض الكتابات المتزامنة والفلاتر السابقة.
- TypeScript وESLint وNext.js build وdiff check ناجحة.
- لا تغيير في API التشغيلي أو migrations؛ إضافة اختبار API فقط. نشر web فقط على نفس المعاينة.
- لا تشغيل أو إيقاف تسلسل ولا تعديل حقول أو عضويات على حساب المستخدم أثناء الفحص المباشر. توثيق النسخة المنشورة يضاف بعد النشر.

لا تزال خصائص AI والترجمة والردود المجدولة الفردية وCRM editor داخل المحادثة وبعض التفاصيل البصرية غير مكتملة. هذه الدفعة ليست ادعاءً باكتمال التطابق.
