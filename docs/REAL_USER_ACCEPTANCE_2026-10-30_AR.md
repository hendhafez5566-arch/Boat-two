## عيوب أُصلحت خلال الاختبار

### أولوية عالية: فحص التدفق يعطي نجاحًا مع مشغّل ناقص

قبل الإصلاح: تغيير نوع المشغّل إلى كلمة مفتاحية ثم الكتابة والانتقال السريع قد لا يثبت قيمة الحقل، لأن تحديثها يعتمد على blur. الحفظ والمحاكي يعرضان VALIDATION، بينما «فحص التدفق» يقول صفر أخطاء.

الإصلاح: تحديث الكلمات ومعرّفات الرد أثناء الكتابة، وفحص الاسم والأولوية والمشغّلات قبل الحفظ والفحص. إعادة الاختبار: الحقل الفارغ أعطى رسالة عربية تحدد المطلوب، وإعادة ملئه وحفظه دون Tab نجحت.

### أولوية عالية: اختفاء عقد خارج الشاشة وفشل إظهار الكل

سببان مؤكدان: عقدة زخرفية غير مقاسة تجعل fitView يتجاهل المحاولة، وتركيز المتصفح يحرك scrollTop مخفيًا داخل حاوية React Flow. قُيد fitView بالعقد المقاسة، وأضيف preventScroll لاستعادة التركيز. المكتبة تفرض overflow:hidden بعد style الممرر لها، لذلك يلزم تجاوز CSS محدد بـ !important لمنع التمرير الأصلي.

إعادة الاختبار على النسخة المنشورة نجحت: overflow=clip وscrollTop=0 بعد فتح محرر العقدة وإغلاقه. إظهار الكل عرض العقد الست المرئية داخل الشاشة؛ أعلى موضع 94 وأسفل موضع 843 ضمن ارتفاع 936. لقطة qa30-canvas-verified.jpg توثق الرسم الفعلي.

### أولوية متوسطة: الأزرار القديمة تُفعّل مجددًا بعد إعادة تحميل الويدجت

أُعيد تحميل الويدجت بعد اكتمال سؤال البريد؛ عاد زر «الأسعار» فعالًا، والضغط عليه أضاف اختيارًا قديمًا دون رد مفيد. الإصلاح يعيد تعطيل الخيارات السابقة عند إعادة عرض كل رسالة واردة من الزائر، ليحاكي ما يحدث وقت الضغط الفعلي. نُشر إصلاح API بنجاح، وأعيد الاختبار بعد انتهاء تخزين السكربت المؤقت: الخياران السابقان معطلان بعد إعادة التحميل. أُرسلت QA30TEST مرة أخرى فظهرت خيارات جديدة فعالة؛ وبعد إعادة التحميل ظلت السابقة معطلة والجديدة فعالة. نجح الاختبار الإيجابي والسلبي.
