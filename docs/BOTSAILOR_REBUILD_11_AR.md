# إعداد حملات البث — المقارنة الحية 27 أكتوبر 2026

تم فتح رابط إنشاء حملة BotSailor مباشرة. المرجع يبدأ بلوحة Configure Action Button ثم Broadcast Campaign ويجمع الاسم ونوع البث والقالب والجمهور في لوحة واحدة.

التنفيذ: وضع reference داخل CampaignComposer مع إبقاء الاستدعاءات القديمة متوافقة، لوحة ConfigurationPanel بدل النافذة الوسطية والمعالج المتتابع، إعدادات ومحتوى ومعاينة في لوحة واحدة، وسم وقائمة للمستهدفين يعملان مع filters الفعلي، إبطال مراجعة الجمهور عند تغيير الفلاتر، واختيار قالب معتمد أو رسالة داخل نافذة الرد في WhatsApp. الحفظ مسودة فقط والجدولة مستقلة. لا توجد اتصالات مدفوعة أو إرسال أو مزامنة قوالب أثناء التنفيذ.

لا يُعتبر إنشاء الحملات مطابقًا بالكامل: تعدد وسوم/قوائم التضمين والاستبعاد، فلاتر البلد والحقول والتاريخ، تعيين وسم بعد البث، Marketing Message API، وربط إنشاء الحملة برسم تدفق ما زالت غير مطابقة. لم تضاف عناصر وهمية لهذه الوظائف.

نجح TypeScript وESLint والبناء الكامل محليًا.
