# إزالة الزيادات وتصحيح أماكن أدوات صندوق الوارد

قرار المالك: حذف الزيادات غير الموجودة في BotSailor. تمت مقارنة المرجع مباشرة: فتح See More، قائمة رأس Chat Actions، وقائمة صف المحادثة. لا تنفيذ لحذف عميل أو سجل محادثة في المرجع أو حساب المستخدم.

## التنفيذ
- حذف التعليق/إلغاء التعليق، اختيار القسم والتوزيع التلقائي من واجهة صندوق الوارد وإزالة طلب departments غير المستخدم.
- حذف تحديد المحادثات بمربعات اختيار والإغلاق الجماعي من الشاشة وإزالة الحالة ومعالج الإغلاق وCSS التابعة لهما.
- نقل المقروءة والأهمية والأرشفة والحل والحظر إلى قائمة صف المحادثة، وهي موضعها في BotSailor؛ القائمة قابلة للإغلاق بـEscape أو الخارج وتُغلق عند التمرير وتمنع تكرار الإجراءات أثناء التنفيذ.
- See More يعرض اختصارات المتابعة والوسوم والفريق والتسلسل والحقول ونافذة الرسائل كشبكة أيقونات؛ هذه الاختصارات تفتح/تركز الحقول المقابلة الموجودة فعليًا.
- نقل اختصار المتابعة من الصف الافتراضي إلى الأدوات الموسعة مثل المرجع.
- إزالة صف الهاتف الإضافي من ملخص العميل، وإظهار مصدر الاشتراك. حالة العميل تستخدم consent للقناة بدل خلطها بحالة المحادثة؛ البيانات غير المتاحة تظهر شرطة، دون اختلاق اشتراك أو مصدر.
- لا حذف لبيانات العملاء أو جداول قاعدة البيانات؛ بقية أقسام المنصة لم تُحذف عشوائيًا دون فحص مرجعها.
