## التنفيذ
- فصل /dashboard/account وتصحيح رابط My Account الذي كان يفتح Settings & Integration.
- ملخص الباقة والصلاحية والفوترة من البيانات الفعلية، دون افتراض Never عند غياب تاريخ معلوم.
- نموذج اسم، بريد للقراءة، هاتف واتساب، عنوان، منطقة زمنية ولغة التطبيق. PATCH /auth/profile يحفظ الملف الشخصي للمستخدم المسجّل فقط؛ اختيار اللغة يحدّث لغة الواجهة المحلية بعد نجاح الحفظ.
- المنطقة الزمنية تستخدم لعرض صلاحية الحساب بهذه الصفحة؛ لا تدّعي تغيير توقيت جدولة الرسائل وباقي المنصة بعد.
- تمت معاينة Usage Log المفتوح مباشرة: جدول MODULE/LIMIT/USED مع البحث. استُخدمت بيانات /workspace لعرض الوحدات المدعومة وحدودها الحقيقية؛ -1 يعرض غير محدود، والحد غير المتاح يعرض شرطة. لم تُنسخ وحدات غير مطبقة أو أرقام حساب المرجع.
- CSS مستقل للتقسيم والبطاقات والحقول والأيقونات واستجابة الشاشات الصغيرة، استنادًا إلى المعاينة المباشرة للمرجع.
- migration094 تضيف account_profile فقط، قابلة للتكرار. لا حذف لبيانات أو حسابات أو تغيير في صلاحياتها.

## التحقق
- اختبار PGlite فعلي: عزل تحديث مستخدم عن الآخر، بقاء كلمة المرور وعضوية الفريق، منع إدخال userId/email/role/password، رفض منطقة زمنية/هاتف/لغة غير صالحة، منع تحديث المستخدم المعطل، وتكرار الترحيل.
- API build وWeb TypeScript وESLint وNext production build ناجحة.
- الفحص المرئي المقارن داخل حساب المنصة الخاصة غير مكتمل بسبب غياب جلسة الدخول؛ معاينة المرجع ليست دليلًا على مطابقة النسخة الخاصة.

## المتبقي
الصفحة ليست مطابقة بالكامل بعد: رفع الصورة، تحديث كلمات المرور الآمن، 2FA، حذف الحساب، ترجمة المحادثة والتوقيع والسجلات التفصيلية. لم توضع أزرار توهم بتنفيذها. مدير الباقات ما زال يحتاج تنفيذًا وصلاحيات مستقلة بدل مسار الفوترة الحالي. لا ادعاء باكتمال مطابقة النظام ككل.
