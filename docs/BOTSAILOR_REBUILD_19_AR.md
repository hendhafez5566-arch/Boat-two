# تنظيف إعدادات الأمان وتكاملات API

## مرجع تمت معاينته مباشرة
- https://botsailor.com/settings ثم API Integration وNew في Email API وAuto Responder API؛ إغلاق النوافذ دون حفظ.
- Security يحتوي Logged-in Devices وLogin Activity وData Delete Activity وMedia Delete Activity وDirect Login وTelegram Security وIP Manager، ولا يحتوي Workspace Settings.
- API Integration يحتوي Email وSMS وAuto Responder وSalla وE-commerce، مع جداول ملفات ربط ونافذة New منفصلة. نافذة Auto Responder تعرض Mailchimp وBrevo وActiveCampaign وMautic وMailWizz. نافذة البريد تعرض SMTP وMailgun وPostmark وSES وMandril.

## تغيير هذه الدفعة
- إزالة تبويب Workspace Settings من إعدادات الأمان وحذف مكوّنه غير المستخدم، دون حذف بيانات الشركة أو endpoints إعداداتها.
- إعادة كتابة IntegrationsPanel بدل تركيب أقسام جديدة فوق القديمة: إزالة أدوات JSON وMock والتنفيذ المباشر وسجل Webhook وإعادة محاولاته وتفويض Google واختيار القناة والتنقل المكرر والنتائج التقنية الخام من هذه الشاشة.
- فصل أنواع الربط المدعومة حاليًا: Email وSMS وAuto Responder وSalla. جدول لكل نوع، بحث وصفحات وأحجام 5/10/20/50/100، ونوافذ إضافة وتعديل مستقلة باستخدام نفس API الفعلي.
- حذف خيارات Google وWebhook من واجهة هذه الصفحة فقط. لا حذف لملفات الربط المخزنة ولا إبطال أو تفعيل أي ملف أثناء العمل. الخلفية لا تزال تخدم وظائفها المرتبطة ببقية النظام.
- التعديل يحتفظ بالمفتاح الحالي عند ترك الحقل فارغًا، ولا يعرض الأسرار المخزنة؛ مانع فوري لتكرار الطلبات وإظهار أخطاء الحفظ داخل النافذة.
- إصلاح توجيه query للإعدادات: workspace/قيم غير معروفة تعود للأمان، وأنواع التكاملات المعروفة فقط تفتح API Integration.

## الحدود
- هذه ليست مطابقة كاملة للمنصة. لا تزال تكاملات SMTP ومزودات البريد والـSMS الأصلية وMailWizz وE-commerce ناقصة؛ Email/SMS الموجودان يستخدمان Gateway حقيقيًا ولا يُعرضان باعتبارهما SMTP أو مزودًا أصليًا وهميًا.
- لم تُضف تبويبات أمان وهمية لوظائف الخلفية الناقصة. سجل النشاط الحالي ما زال عامًا ويحتاج مطابقة Login Activity وبقية سجلات المرجع.
- الصفحة داخل حساب المستخدم تعيد التوجيه إلى /login؛ لا جلسة صالحة متاحة للفحص المرئي، ولم تتكرر طلبات الدخول المعلقة سابقًا. مرجع BotSailor متاح وتمت معاينته مباشرة.
- لا إرسال فعلي، ولا تفعيل تكامل، ولا تعديل لسجلات العملاء أثناء التحقق.
