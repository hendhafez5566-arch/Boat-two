# حالة المطابقة العامة — 29 أكتوبر 2026

المطابقة الكاملة لم تُنجز بعد. لا تُحتسب اختبارات البناء أو تقارير التنفيذ دليلًا على تطابق بصري داخل حساب المستخدم؛ جلسة المستخدم غير متاحة حاليًا وتعيد إلى /login. المرجع تمت معاينته مباشرة في الدفعات ذات الصلة.

| القسم | ما أُنجز في الدفعات الأخيرة | المتبقي المؤكد |
|---|---|---|
| الشريط والقوائم | إزالة المداخل الزائدة ومبدّل مساحة العمل غير الموجود في الشريط المقابل | قائمة الحساب وصفحته والتفاصيل البصرية |
| لوحة المعلومات | حذف البطاقات الزائدة، نمو 30 يومًا وفلتر منصة وAI من بيانات فعلية | فحص مرئي داخل الحساب وتفاصيل المرجع المتبقية |
| صندوق الوارد | تخطيط وأدوات عميل وCRM وحقول وتسلسلات، إزالة الزيادات المؤكدة | بعض الإجراءات الناقصة والتفاصيل البصرية واختبار الحساب |
| إدارة البوت | إجراءات الصف وOptions، إزالة المعالج وتفاصيل التدفق، توجيه Integrations الصحيح | بدء محرر غير محفوظ، بقية Options وCopy to other Bot وWebhook والمصمم |
| النشر الاجتماعي | فصل الصفحة والأنواع والقوائم والنماذج والمعاينة وحفظ اسم وتصنيف الحملة | رفع الوسائط والتكرار وتوقيت الحساب والتصفح من الخادم وبقية إمكانات المزود |
| الإعدادات | إزالة تبويب الشركة وأدوات المطورين، تنظيم ملفات الربط | SMTP ومزودات ناقصة وسجلات الأمان المطابقة |
| الفوترة | ملخص وسجل مدفوعات وفلترة؛ فصل الترقية وإزالة أدوات التشغيل | المعاملات اليدوية والحقول التاريخية ودعم توقيت الحساب |
| مدير الباقات | ما زال المسار القديم مرتبطًا بالفوترة | تنفيذ مستقل مطابق، دون ادعاء وجود CRUD غير مطبق |
| مدير المستخدمين | المرجع List متاح، Create يعيد 403 | المقارنة المصرح بها للنموذج والفرق بين المشتركين والفريق |
| الحساب | صفحة مستقلة، ملخص اشتراك، حفظ ملف المستخدم ولغة الواجهة، عرض الاستخدام الفعلي | الصورة وكلمات المرور و2FA والحذف والتوقيع والترجمة والسجلات التفصيلية والفحص المرئي |
| المشتركين والبث وربط الحسابات | توجد تطبيقات سابقة | مراجعة مباشرة جديدة لبقية الفروق والوظائف داخل الحساب |
| التجارة والمواعيد | فصل النشر وإزالة نتائج JSON من الاستخدام | نماذج وتخطيط ووظائف مطابقة مستقلة |

لا بيانات عملاء أو تدفقات أو اشتراكات حقيقية حُذفت بغرض المطابقة. أي حذف للواجهة تم في الكود المرتبط بها مع الحفاظ على البيانات. لا يجوز تقديم أي صف في الجدول باعتباره مطابقًا بالكامل اعتمادًا على اختبارات البناء وحدها.
