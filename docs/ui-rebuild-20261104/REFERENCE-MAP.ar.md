## فروق مثبتة قبل التعديل

- مدير Boat يحتفظ بقائمة ‏260px ويضيّق الجدول؛ المرجع يصغرها إلى ‏90px.
- مصمم Boat يعرض قائمتي تنقل وأدوات متجاورتين؛ المرجع dock واحد.
- إحصاءات العقد تظهر رغم تعطيل عرض الأداء؛ المرجع أقل ازدحامًا.
- أزرار الحذف العائمة على كل عقدة ووصلة تزحم canvas قبل تحديد عنصر.
- 48 موضع summary في المصدر؛ بعضها مصمم بالفعل (Inbox/Account/Audience)، والبقية تحتاج عنوانًا وأيقونة وحالات تفاعل موحدة.
- حالة التدفق العربية تتحول إلى شارة طويلة مقسمة إلى أسطر؛ إجراءات الجدول تُقصّ عند ضيق المساحة.
