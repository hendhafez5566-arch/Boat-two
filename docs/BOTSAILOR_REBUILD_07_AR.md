# مطابقة البنية البصرية للوحة إعداد العقد — 07

## مرجع تمت معاينته فعليًا

من نافذة Configure Interactive Message في BotSailor، على نافذة متصفح 1363×936:

- الإعدادات لوحة جانبية وليست نافذة وسطية؛ عرضها 576px، ولا يوجد تعتيم أو ضبابية للرسم.
- عنوان اللوحة 20px/25px، وخط الواجهة Plus Jakarta Sans.
- الحقول: خلفية rgb(253,253,255)، وحدود rgb(228,230,252)، وارتفاع 42px، وزوايا 8px، وحشو 10px 15px.
- بطاقات الأقسام: حدود rgb(226,232,240)، وزوايا 12px، وفاصل 14px بين البطاقات.
- زر الحفظ: خلفية وحدود rgb(13,139,241)، وزوايا 8px، وظل 0 2px 6px rgb(172,181,246).
- العنوان/المحتوى/التذييل لها أيقونات منفصلة، وشارات الاختياري بنفسجية وخضراء. اختيار النص/الوسائط يتم ببطاقتين.

## التنفيذ

- استبدال Dialog الوسطي الخاص بإعدادات العقد بمكوّن ConfigurationPanel جانبي غير نمطي (aria-modal=false). يظهر من اليمين للعربية ومن اليسار للإنجليزية، ويصبح بعرض الشاشة على الهاتف.
- إزالة CSS القديمة الخاصة بالنافذة الوسطية بدل تغطيتها بطبقة جديدة. يظل Dialog الخاص بالمحاكاة مستقلًا.
- تثبيت التذييل خارج المنطقة القابلة للتمرير، والحفاظ على Escape والإغلاق والحفظ المؤجل للعقدة.
- تحميل الخط محليًا ضمن حزمة الموقع عبر Fontsource، دون اعتماد على طلب Google Fonts وقت التشغيل.
- إعادة ضبط المكوّنات المشتركة: الحقول، بطاقات الأقسام، الأيقونات، ألوان الشارات، زر الحفظ، والمسافات. نقل عدادات الأحرف إلى داخل الحقول.
- استبدال قائمة نوع العنوان ببطاقتي نص/وسائط، مع إبقاء مخطط بيانات العنوان الحالي متوافقًا. الوسائط الحالية لا تزال تدعم عنوان الصورة؛ الفيديو/الملف ليست وظائف مطبقة بهذه الدفعة.

## التحقق

TypeScript وESLint وبناء Next للإنتاج ناجحة. اختبارات المكونات الفعلية والحفظ/الإغلاق وفصل النوافذ والوصلات وتحويل الاختيارات ناجحة. يلزم التحقق البصري على الإصدار الحي بعد اكتمال النشر؛ لا يصح الاستدلال من الكود وحده على التطابق البصري.

## النطاق المتبقي

لا تعني هذه الدفعة أن جميع صفحات المنصة أو الوظائف أصبحت مطابقة. أتمتة الأزرار وخيارات بدء التدفقات وإجراءات النظام وعناوين الفيديو/الملف وبقية الصفحات لم تكتمل مطابقتها. هذا التسليم يعالج بنية وشكل لوحة الإعداد المشتركة بعد المقارنة البصرية المباشرة.
