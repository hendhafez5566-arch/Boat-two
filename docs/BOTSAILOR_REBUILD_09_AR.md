# متابعة مطابقة الأقسام — 26 أكتوبر 2026

## المنفذ
- مدير البوت: عرض حسابات 300px، مسافة 16px، اختيار أول حساب عند عدم تحديد حساب، جدول الردود بمعرف فعلي واسم مرجعي وتاريخ، فرز فعلي، اختصارات النسخ والتصدير والتعديل والمجلد.
- تدفقات جمع البيانات: جدول مستقل بثلاثة أعمدة؛ تصفية تدفقات إدخال المستخدم محفوظة.
- أقسام AI: صفحة إعداد مستقلة لتوجيه المساعد إلى الحساب عبر API الموجود. لا يوجد مفتاح تشغيل وهمي؛ تعطيل حساب واحد مع بقاء المساعد الافتراضي يتطلب دعمًا إضافيًا بالمحرك.
- أقسام الحساب الستة: سطح ومقاسات وخطوط مشتركة؛ التكاملات تقبل مسار autoresponder.
- الإعدادات: تنقل جانبي بمستويين، الجلسات ببحث وترقيم صفحات، سجل النشاط معاد استخدامه كمكوّن مستقل، إعدادات الشركة ما زالت متاحة.
- الخط والخلفية واللون الافتراضي وارتفاع الشريط العلوي مشتركة في صفحات لوحة التحكم؛ إعدادات هوية المستأجر ما زالت محفوظة.

## حدود المطابقة
هذا ليس إثبات تطابق المنصة بالكامل. لا تزال هناك فروق في محتوى التجارة وتكاملات خدمات البريد وSMS وسجل الدخول وحذف الوسائط وإعدادات IP ووظائف AI المتقدمة وصفحات البث والوارد. لم تُضف أزرار لهذه الوظائف باعتبارها منفذة.
لم يتم إرسال رسائل أو نشر تدفقات أو تشغيل مزود مدفوع أو إبطال جلسات أثناء التحقق.
