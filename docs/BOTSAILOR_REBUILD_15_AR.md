# مطابقة هندسة صندوق الوارد ولوحة العميل

مقارنة مباشرة داخل BotSailor بنفس أبعاد المتصفح 1363×936، ثم تعديل مكونات الشاشة الأساسية بدل تكرار تنسيقات عامة.

## قياسات المرجع
- شريط التنقل 75px، قائمة المحادثات 380px، لوحة الإجراءات 385px.
- خلفية المحادثة #fbfbfc، لوحة العميل #f8f9fb.
- ارتفاع رأس المحادثة 74px، رأس إجراءات العميل 71px.
- بطاقة CRM حوالي 260px بدل 314px سابقًا؛ صفوف 11px/14.3px وفواصل 8px؛ عناوين 13px، زوايا 12px، أيقونات دلالية لكل صف.
- شريط معلومات العميل: عناوين 10.5px/13.65px، قيم 11px/12.65px؛ أيقونات عين/لغة/موقع/عميل منذ بدل تكرار الكرة الأرضية والساعة.
- الوقت وحالة الإرسال خارج الفقاعة مع التاريخ، وإخفاء عناصر اختيار المجموعة لا يترك فراغًا قبل صورة العميل.

## وظائف مرتبطة فعليًا
- فصل نموذج المتابعة إلى مكون واحد يديره صندوق الوارد، متاح من الرأس واللوحة حتى إذا كانت اللوحة الجانبية مطوية.
- تعديل اسم العميل من الرأس والبريد من ملخص العميل عبر PATCH profile مع expectedUpdatedAt، وإعادة قراءة القائمة والملف بعد الحفظ.
- اختيار رموز تعبيرية محلي يدرج الرمز عند موضع المؤشر؛ إغلاق بخارج النافذة أو Escape؛ لا إرسال تلقائي.
- إزالة شرائح البوت/الموظف وغير المعين من صف القائمة؛ هذه البيانات باقية في لوحة الإجراءات.

لا تغيير API أو قاعدة البيانات. لا ربط خارجي ولا رسائل حقيقية. خصائص Pause AI والردود المجدولة والتحليل والترجمة وتفعيل التسلسلات لا تزال غير مطابقة بالكامل، ولا أزرار وهمية لها. نموذج المتابعة لا يزال دون حقل ملاحظة منفصل.
