## استخدام النظام

1. التجارة ← مصادر البيانات ← إضافة مصدر، ثم رفع Excel/CSV واختيار ورقة البيانات.
2. ربط معرف ثابت واسم وقسم وحالة ظهور؛ تحديد أسماء الحقول والأسعار التي تريد عرضها.
3. حفظ الربط ← مزامنة ومعاينة ← مراجعة الأخطاء ← تطبيق.
4. في المصمم: رسالة ترحيب ← عقدة كتالوج ديناميكي، اختيار المصدر والأقسام والحقول ← تحويل لموظف. اربط القناة الصحيحة وحدد المشغل ثم احفظ وانشر.
5. حدّث نفس المصدر لاحقًا دون تعديل التدفق. تغيير ظاهر/مخفي يُطبق بعد المزامنة. حذف صف لا يؤرشفه إلا بتأكيد واضح؛ الملفات المحلية تتطلب رفع نسخة أحدث.

موارد الاستمرار: التدفق `146753b1-f7cb-4a45-bd19-631174f00e76`، قناة QA `4d54b814-61a0-464c-b2be-8fe9e8192582`. مصدر السياحة `3fd9ef62-5b93-4666-9b06-932b32347873`، الملابس `bd1b6ea4-a2fd-4140-8d3e-d6d042e64c45`. كل البيانات اصطناعية. أُعيدت مسودة البوت إلى مصدر السياحة وبحث فارغ؛ النسخة المنشورة v2 مقيدة بقناة QA وكلمتها.
