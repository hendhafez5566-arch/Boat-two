# مطابقة إدارة البوت وإزالة الزيادات المؤكدة

## المقارنة المباشرة
- زيارة Bot Manager في BotSailor وفحص Keyword Replies وOptions وإجراءات الصف، ثم Webhook Workflows.
- فتح Create: المرجع يفتح Flow Builder في تبويب مستقل، بعقدة Start Bot Flow وشريط Back/Rearrange/Save؛ لم يُحفظ أو يُرسل شيء. معاينة حقول Start المتعمقة تعذرت بسبب مهلة المتصفح، فلا ادعاء بفحصها.
- النقر على Integrations نقل فعلًا إلى https://botsailor.com/settings?action=emailauto-tab؛ الرابط الظاهر داخل مدير البوت وحده لم يكن كافيًا لاكتشاف ذلك.

## التنفيذ
- حذف قائمة الإجراءات الزائدة لكل صف، ومنها Flow Details وإيقاف النشر وتكرار النسخ والنقل. تبقى إجراءات الصف المباشرة: Duplicate، Export، Edit، Delete، Move to Folder، بترتيب المرجع في حدود الوظائف الموجودة فعليًا.
- نقل استيراد التدفق من الشريط المنفصل أسفل الجدول إلى Options أعلى مدير البوت. لا إضافة خيارات وهمية لـReset/Variables/Logs/Folder manager غير المتصلة بخلفية فعلية.
- حذف صفحة المعالج الموجه القديمة ومسار تفاصيل التدفق المنفصل: الروابط القديمة تعود إلى مدير البوت والمصمم، وحذف مساعدات المعالج غير المستخدمة وقواعد CSS الخاصة به. إزالة مدخل تفاصيل التدفق من قائمة المصمم أيضًا. المسودات والتدفقات المحفوظة باقية.
- حذف اختيار القالب وReusable component والمعالج الموجه من نافذة الإنشاء، وإزالة طلب templates والحالة وCSS المرتبطة بالواجهة المحذوفة. تبقى تسمية التدفق مطلوبة لعقد API الحالي؛ الإنشاء بدون بوت محدد أصبح ممنوعًا، فلا تُنشأ مسودة عامة بالخطأ.
- Integrations وAuto Responder في مدير البوت ينقلان إلى تبويب Auto Responder في الإعدادات، بما في ذلك الروابط القديمة المباشرة؛ إزالة العرض الداخلي الخاطئ لهذه الأدوات من مسار الاستخدام.
- إزالة عرض ملفات تكامل البريد الخاطئ عند فتح Webhook Workflows؛ يظهر أن الوظيفة غير متاحة بدل عرض وظيفة أخرى تحت الاسم نفسه.
- تحسين رأس البوت بعرض معرّفه الفعلي بدل تكرار نوع المنصة، وترجمة الحالة وإضافة أيقونة حذف صحيحة. لا استنتاج رقم هاتف غير متاح من البيانات.
- حفظ وظائف الحذف/النسخ/التصدير والنقل الحالية دون تنفيذ أي منها على بيانات حقيقية أثناء العمل. لم تتغير دورة الحفظ والنشر الحالية داخل المصمم حتى لا يتحول حفظ مسودة إلى تشغيل بوت دون قصد.

## الحدود
- ليست مطابقة كاملة لإدارة البوت أو المصمم. Create في المرجع يبدأ محررًا غير محفوظ مباشرة؛ عقد النظام الحالي ما زال ينشئ مسودة باسم أولًا. Copy to other Bot وبقية Options ونظام Webhook Workflows الحقيقي وتفاصيل المحرر تحتاج عملًا مستقلًا.
- لا تدفقات أو حسابات أو مجلدات محفوظة حُذفت، ولا نُشر أو أُوقف بوت فعلي. أزيلت الواجهات المتعارضة فقط.
- لا جلسة صالحة داخل حساب المستخدم للفحص المرئي؛ المقارنة المباشرة تمت للمرجع، ولا تُعرض لقطة قديمة باعتبارها دليل النسخة الحالية.
