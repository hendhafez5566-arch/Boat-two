# مطابقة الفوترة وإزالة أدوات التشغيل الزائدة

## مقارنة مباشرة
- زيارة User Manager ثم Create: المرجع أعاد 403 لصلاحيات الحساب؛ لم نفترض حقول إنشاء أو نوسّع صلاحيات النظام لمحاكاتها.
- زيارة https://botsailor.com/payment/transaction-log وManual Transactions والرجوع؛ معاينة الصفحة بالصورة، دون إرسال أو دفع أو حفظ في المرجع.
- Billing: عنوان ووصف، ملخص Package / Price & Validity / Account Expiry، Upgrade to Pro إلى صفحة تسعير، ثم Transaction Log مع البحث والتاريخ وجدول المعاملات. المعاملات اليدوية منفصلة.

## التنفيذ
- استبدال واجهة الفوترة القديمة بملخص الاشتراك وسجل المدفوعات الفعلية. حذف مكوّنات BillingInvoices وBillingEvents وBillingReconciliation وSubscriptionRequests بعد التأكد من أنها لم تعد مستوردة.
- إزالة بطاقات الاستهلاك والباقات وأدوات التسوية وطلبات تغيير الاشتراك وسجل أحداث Stripe ورسائل إعداد المتغيرات والأدوات التشغيلية من واجهة الفوترة.
- صفحة /dashboard/pricing مستقلة لاختيار الباقة وبوابة إدارة الدفع الفعليتين الموجودتين سابقًا؛ تحديث Upgrade to Pro في قائمة الحساب. لم تُنفّذ أي عملية دفع أثناء العمل.
- توسيع GET /billing/invoices مع الحفاظ على الواجهة القديمة: status افتراضي all وlimit افتراضي 50، إضافة search وfrom/to وlimit المسموح 5/10/25/50/100/200/500، وإرجاع paid_at وبيانات الفلتر لمنع عرض نتائج بحث سابق أثناء تغييره.
- السجل الجديد يطلب status=paid. تصفية التاريخ نصف مفتوحة بتوقيت UTC، والبحث حرفي في رقم/معرف الفاتورة وليس SQL wildcard. count وitems يستخدمان نفس الشروط، والصلاحيات وwithTenant/RLS محفوظة.
- تنسيق مبالغ العملات صفرية وثلاثية المنازل مثل JPY/KWD، وروابط الفواتير HTTPS على نطاقات Stripe فقط. ترك حقول البريد والمنتج والنوع ودورة الفوترة غير المحفوظة بشرطة بدل استعارتها من الاشتراك الحالي.

## التحقق
- PostgreSQL محلي بمستخدم NOBYPASSRLS: فصل الشركة الأخرى، حدود UTC مع جلسة Asia/Dhaka، البحث الحرفي %_، صفحات متسقة بلا تكرار، سجل غير مؤرخ، الإعدادات الافتراضية والحقول غير الصالحة: ناجح.
- اختبارات العملات وروابط الفواتير: ناجحة. الإجمالي 3 اختبارات ناجحة.
- TypeScript وESLint وAPI build وgit diff --check: ناجحة. Next.js build كامل ناجح (41 صفحة). API منشور SUCCESS: ce43322c-074f-46d9-8aa8-b0730026cfef على commit c6d9ec4f08b93413b11a95e0b0ce4a0115d33b38. الواجهة ستنشر مع دفعة إدارة البوت 22.
- لا تغيير لمخطط البيانات ولا حذف لفواتير أو حسابات أو تعديل اشتراك أو إرسال بريد أو تشغيل دفع أو تسوية خارجية.

## حدود المطابقة
- ليست مطابقة كاملة للمنصة. سجل الفوترة يعتمد الفواتير المدفوعة المحفوظة، وليس كل أنواع معاملات BotSailor. بيانات البريد والمنتج ودورة الفوترة التاريخية والمعاملات اليدوية غير متاحة بعد؛ لم تُختلق بيانات أو أزرار لهذه الوظائف.
- لا تحديد جماعي بلا عملية حقيقية. Package Manager ما زال يحتاج تنفيذه المستقل بدل الربط القديم بصفحة الفوترة. صفحة التسعير تعرض الباقات الفعلية ولا تدّعي مزايا أو أسعار المرجع.
- تواريخ الفلتر UTC حاليًا وتحتاج مطابقة تفضيلات توقيت الحساب. لا جلسة دخول صالحة لمنصة المستخدم للفحص المرئي؛ المقارنة المباشرة متاحة للمرجع فقط، ولم تتكرر طلبات الدخول المعلقة.
