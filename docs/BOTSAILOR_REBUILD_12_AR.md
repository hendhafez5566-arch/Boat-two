# مطابقة فلاتر جمهور الحملات

تمت مراجعة لوحة Configure Action Button / Broadcasting مباشرة في BotSailor بتاريخ 27 أكتوبر 2026، بما فيها فتح قائمة الوسوم.

أصبحت لوحة إنشاء الحملة تدعم اختيارًا متعددًا قابلًا للبحث لكل من تضمين الوسوم، استبعاد الوسوم، تضمين قوائم المشتركين، واستبعاد قوائم المشتركين. مصدر الخيارات بيانات مساحة العمل الفعلية. لا تضيف الواجهة وسومًا وهمية ولا تقصرها على أول صفحة جهات اتصال.

التضمين يطابق أي قيمة في المجموعة؛ المجموعات المختلفة تتقاطع، والاستبعاد يتغلب على التضمين. تستخدم مراجعة الجمهور وتنفيذ الحملة contactWhere نفسه. بقي دعم فلاتر الحملات القديمة. لا تعني عضوية قائمة أو وجود وسم موافقة على الرسائل: فحص الموافقة وربط القناة وسياسة الإرسال مستمر.

تغيير أي مجموعة يلغي مراجعة الجمهور السابقة. لم يتم إنشاء أو إرسال حملة أثناء التحقق. لم يتم دمج فرع المعاينة في main.

التحقق: اختبار PostgreSQL فعلي للتضمين والاستبعاد والتداخل والقيم الفارغة والقيم الخاصة، جميع اختبارات business (11 اختبارًا)، بناء API، بناء Next.js، وESLint للمكونات المتغيرة.

المطابقة الكاملة لا تزال غير مكتملة: البلد والحقول المخصصة وتاريخ إضافة المشترك وتعيين الوسم بعد البث وMarketing Message API وإنشاء الحملة عبر مخطط الأتمتة ما زالت تحتاج عملًا واختبارًا منفصلًا.
